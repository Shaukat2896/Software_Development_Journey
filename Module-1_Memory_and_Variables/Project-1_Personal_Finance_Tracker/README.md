# Personal Expense Assistant

**Author:** HiddenCrafts alias Muchukota Shaukat

## Version 1

### Overview

Personal Expense Assistant is a Command Line Interface (CLI) based application developed as part of the Software Engineering Journey.

The application helps users track their monthly expenses and generate a simple financial report containing total expenses, remaining balance, and savings percentage.

---

## Features

* Monthly income tracking
* Multiple expense entry
* Automatic expense calculation
* Remaining balance calculation
* Savings percentage calculation
* Menu-driven interface
* Continuous execution using a loop until the user chooses to exit

---

## Inputs

The application requires:

* Monthly salary
* Number of expenses
* Expense names
* Expense amounts

---

## Outputs

The application generates:

* Total monthly expenses
* Remaining balance
* Savings percentage
* Monthly financial report

---

## Program Flow

User Input
→ Expense Collection
→ Expense Calculation
→ Savings Calculation
→ Financial Report Generation
